# Machine Learning Course

Coursework, experiments, presentations, and project materials from CSCE 5063: Introduction to Machine Learning at the University of Arkansas, taught by Dr. Ukash Nakarmi. The project team consisted of Arna Nishita Nithila and Shakil A. Rafi.

## Repository map

- `MiniProjects/` — focused implementations and experiments, including MNIST work
- `ReadingAssignments/` — written reading responses and source files
- `Prototyping/` — exploratory notebooks and data experiments
- `Final Project/` — final-project analysis and artifacts
- `Report/` — written project materials
- root PDF files — presentation-ready posters

## Working with the notebooks

The repository is a historical course archive rather than a single installable package. Create an isolated Python environment and inspect each notebook's imports before running it; dependency versions are not locked globally.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install jupyter
jupyter lab
```

Some datasets and model artifacts are intentionally retained as part of the course record. Confirm each dataset's source and reuse terms before redistribution.

Small `.icloud` metadata stubs are also retained because the corresponding source artifacts were already absent when this cleanup began. They preserve evidence of unresolved files; they are not the original documents or datasets.
